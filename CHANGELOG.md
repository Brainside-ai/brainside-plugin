# Changelog

Todas as mudanças deste plugin. Cada versão sobe o `version` em `plugins/brainside/.claude-plugin/plugin.json`.

## 0.1.0 — 2026-10-21

- Primeira versão pública (beta).
- Skill `brainside`: buscar no Brainside antes de responder; salvar sozinho o conhecimento durável e avisar; perguntar antes de mudar, apagar, mexer em regras, gravar dado sensível ou conteúdo externo; nunca guardar segredos.
- Conector MCP `https://api.brainside.ai/mcp` (HTTP + OAuth no brainside.ai).
- Texto equivalente para as instruções personalizadas do ChatGPT.
- `INSTALL.md` escrito para IAs.
